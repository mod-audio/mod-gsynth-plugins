# mod-gsynth-acid-bass

A squelchy monophonic bass synth played from a guitar or bass: one oscillator an octave below what you play, into a resonant filter that your picking opens. Dig in for the squelch. Play single notes; the original signal is not mixed into the output.

Accent sets how far your picking opens the filter. Sweep opens the filter slowly while it is on; it is made for a footswitch.

One voicing of MOD's "GSYNTH:Flexible" pedalboard.

LV2 plugin, `https://mod.audio/plugins/gsynth-acid-bass`. One audio input, stereo output.

## Controls

| Control | Type | Range | Default |
| --- | --- | --- | --- |
| Wave | enum | 2..3 | 2 |
| Cutoff | float | 0.0..6.0 | 2.0 |
| Resonance | float | 0.01..1.0 | 0.876 |
| Accent | float | 0.0..10.0 | 6.45 |
| Sweep | toggle | 0..1 | 0 |
| Reverb | float | 0.0..0.6 | 0.195 |
| Level | float | -20.0..20.0 | 0.0 |

Presets: Acid Saw, Acid Square.

## Where it comes from

Generated by MOD Audio's mod-gsynth-creator from the pedalboard **GSYNTH:Flexible**, snapshot **Acid Saw Bass / Acid Square Bass**. The signal chain is that pedalboard's, in one plugin.
`src/engines/flexible.h` draws the signal chain and holds its fixed values; `src/synth_config.h` holds this synth's
voicing and controls. The blocks in `src/blocks/` are ports of the plugins MOD's GSYNTH pedalboards are built from,
plus a few written for this project:

## Building

Needs the LV2 headers and single-precision FFTW (`fftw3f`).

```sh
cmake -S . -B build && cmake --build build
```

This tree is complete on its own. It was generated; to change the synth, change its spec and export again.
