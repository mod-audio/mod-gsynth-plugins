# mod-gsynth-minor-dub

Every note you play becomes a minor chord: three sawtooth oscillators a minor third and a fifth apart, through a mellow filter into a dub delay and a plate reverb. Play single notes on a guitar or bass; the original signal is not mixed into the output.

Echo brings the delay up and lengthens its repeats together. Space does the same for the reverb.

One voicing of MOD's "GSYNTH:Flexible" pedalboard.

LV2 plugin, `https://mod.audio/plugins/gsynth-minor-dub`. One audio input, stereo output.

## Controls

| Control | Type | Range | Default |
| --- | --- | --- | --- |
| Cutoff | float | 0.0..6.0 | 2.1 |
| Resonance | float | 0.01..1.0 | 0.376 |
| Echo | float (macro) | 0.0..1.0 | 0.5 |
| Space | float (macro) | 0.0..1.0 | 0.4 |
| Level | float | -20.0..20.0 | 0.0 |

Presets: Minor Dub, Deep Dub, Wide Space.

## Where it comes from

Generated by MOD Audio's mod-gsynth-creator from the pedalboard **GSYNTH:Flexible**, snapshot **Minor Dub**. The signal chain is that pedalboard's, in one plugin.
`src/engines/flexible.h` draws the signal chain and holds its fixed values; `src/synth_config.h` holds this synth's
voicing and controls. The blocks in `src/blocks/` are ports of the plugins MOD's GSYNTH pedalboards are built from,
plus a few written for this project:

## Building

Needs the LV2 headers and single-precision FFTW (`fftw3f`).

```sh
cmake -S . -B build && cmake --build build
```

This tree is complete on its own. It was generated; to change the synth, change its spec and export again.
